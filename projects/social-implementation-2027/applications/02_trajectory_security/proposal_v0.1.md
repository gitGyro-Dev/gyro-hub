# 応募概要 v0.1（レビュー前原案）

## タイトル
攻撃の原因がわからなくても異常に気づくセキュリティ

## 概要
道路の通常では考えられない場所に車が止まっていたとします。そこに至った経緯や原因がわからなくても、何か異常なことが起きた可能性には気づくことができます。

この考え方を、情報システムのセキュリティに応用します。

従来の攻撃手法や脆弱性の特定に加え、システムの状態がどのような関係を保ちながら変化しているか、その推移（Trajectory）に着目します。

正常な状態の推移からの逸脱を評価し、原因が特定できていない段階でも、追加確認、権限の制限、処理の停止など、状況に応じた対応を判断する仕組みを提案します。

現在、独自の情報処理理論であるGyro Logicを背景に、Trajectoryに基づく脆弱性対応の論文を公開し、概念実証（PoC）を進めています。

未知の脆弱性や正規アカウントを悪用した攻撃に対して、攻撃を完全に防ぐことだけを目指すのではなく、異常の早期認識と被害の抑制を目指します。

既存のセキュリティ製品に追加できる技術として発展させ、攻撃手法の変化にも対応できる多層的な防御基盤の実現を目指します。
