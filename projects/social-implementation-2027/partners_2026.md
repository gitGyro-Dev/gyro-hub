## 次の調査
1. 優先候補を業種別に比較。2025年度受賞企業の選好と実際の受賞例は別途調査。
2. 各社の一次資料（研究テーマ、プロダクト、セキュリティ技術、協業制度）を確認し、出典・確認日・差別化仮説を追加。
3. 候補を Core theory / Runtime / Authentication / Vulnerability response / Outreach に分け、相手の事業課題から提案を再構成。
4. 協賛企業へ応募者側から本プログラムを通じた直接・間接交渉はできない点に留意。
